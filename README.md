# JARVIS для macOS

Нативный AI-ассистент для macOS на C++17 и AppKit (Objective-C++). Эта версия
переводит проект со старой Python-реализации на нативное приложение и использует
локальный сервис OpenCode для общения с настроенной AI-моделью.

## Что входит в обновление

- Python-код заменён нативной реализацией на C++17 и AppKit; для сборки проекта
  не нужны Python и `pip`.
- Добавлен оконный интерфейс macOS с чатом, индикатором модели и счётчиком
  сообщений.
- Подключён OpenCode: приложение находит локальный сервис и использует
  настроенного в нём провайдера и модель.
- Добавлены голосовой ввод на русском языке через Apple Speech Framework и
  озвучивание ответов системной командой `say`.
- Добавлена передача изображения из файла и скриншота экрана vision-модели.
- Добавлены команды для открытия приложений и сайтов, а также CLI-режим для
  запросов без окна.
- Добавлена кнопка сброса контекста текущего диалога.

## Требования

- macOS.
- Xcode Command Line Tools с `clang++`, `make` и macOS SDK.
- Установленный и настроенный [OpenCode](https://opencode.ai/), доступный как
  команда `opencode`.
- Провайдер и модель, настроенные в OpenCode. Для обычного текста JARVIS
  использует модель по умолчанию из OpenCode; для изображений выбирается
  `glm-5.3-flash-free`.
- Системный `libcurl` (используется при сборке через `-lcurl`).

## Установка и настройка

### 1. Установите инструменты сборки

Откройте Terminal и установите Xcode Command Line Tools:

```sh
xcode-select --install
```

Если инструменты уже установлены, macOS сообщит об этом.

### 2. Установите и настройте OpenCode

Установите OpenCode по официальной инструкции и настройте в нём AI-провайдера.
Затем запустите:

```sh
opencode
```

JARVIS читает адрес сервиса и пароль из
`~/.local/state/opencode/service.json`. Если этого файла нет, сначала запустите
OpenCode и проверьте, что локальный сервис успешно стартовал. Убедитесь, что
настроенный провайдер авторизован и выбранная модель доступна. Приложение не
содержит API-ключей провайдера: запросы отправляются через локальный OpenCode.

### 3. Соберите приложение

Перейдите в каталог проекта и запустите `make`:

```sh
cd ~/Downloads/JarvisCPP
make
```

Сборка создаст исполняемый файл `build/jarvis`. Очистить объектные файлы и
бинарник можно командой:

```sh
make clean
```

### 4. Запустите JARVIS

Оконный режим:

```sh
./build/jarvis
```

CLI-режим:

```sh
./build/jarvis "Привет, JARVIS"
```

Запрос с изображением:

```sh
./build/jarvis --image "/путь/к/изображению.png" "Что изображено?"
```

Сбросить диалог OpenCode:

```sh
./build/jarvis --reset
```

Для CLI-команд OpenCode должен быть запущен и доступен локально так же, как и
для оконного приложения.

## Работа в оконном приложении

1. Введите сообщение и нажмите **Отправить**. Ответ будет показан в чате и
   озвучен.
2. Нажмите **🎤**, произнесите запрос на русском языке. Повторное нажатие
   останавливает запись; распознавание также завершает работу после паузы.
3. Нажмите **📎**, чтобы выбрать изображение PNG или JPEG. Добавьте вопрос и
   нажмите **Отправить**. Если текст не введён, JARVIS попросит модель описать
   изображение.
4. Нажмите **👁**, чтобы сделать скриншот экрана, затем отправьте его с вопросом.
5. Нажмите **⛔**, чтобы остановить озвучивание текущего ответа.
6. Нажмите **🧠**, чтобы удалить текущую сессию OpenCode и начать новый диалог.

При первом использовании микрофона и распознавания речи macOS может запросить
соответствующие разрешения. Разрешения можно проверить в **System Settings →
Privacy & Security**. Для снимков экрана macOS также может запросить разрешение
на запись экрана.

## Команды и действия

Ассистент понимает команды открыть приложение, сайт или выполнить поиск в
Google. В оконном режиме некоторые частые команды обрабатываются напрямую:

- YouTube и Google открываются в браузере;
- команды про Safari запускают Safari;
- команды про музыку запускают приложение «Яндекс Музыка».

Остальные действия модель возвращает в формате `ACTION`, а обработчик
поддерживает `OPEN_APP`, `OPEN_SITE` и `SEARCH_GOOGLE`. Эти действия открывают
приложения, сайты или страницу поиска; произвольные команды оболочки не являются
частью пользовательского интерфейса JARVIS.

## Как устроен проект

- `src/http.*` — HTTP-клиент на libcurl, авторизация локального сервиса и
  обнаружение OpenCode по `service.json`.
- `src/ai.*` — сессии, выбор модели, отправка запросов и обработка ответов.
- `src/memory.*` — счётчик сообщений и состояние прикреплённого изображения;
  историю диалога хранит сессия OpenCode.
- `src/gui.*` — нативное окно macOS и обработчики кнопок.
- `src/speech.*` — распознавание речи Apple Speech Framework и озвучивание
  через `say`.
- `src/commands.*` и `src/executor.*` — быстрые команды и поддерживаемые
  действия ассистента.
- `src/main.cpp` — выбор между GUI- и CLI-режимом.
- `Makefile` — сборка приложения.

Текстовые запросы и выбранные изображения передаются локальному сервису
OpenCode, а дальнейшая обработка зависит от выбранного в OpenCode провайдера.
Скриншоты сохраняются в `screens/` рядом с рабочим каталогом; если туда нельзя
записать файл, используется временный каталог системы.

## Новая версия: Siri-шарик (папка `JarvisSiriOrb`)

В репозитории добавлена отдельная папка с улучшенной версией: приложение
работает как плавающий Siri-шарик поверх всех окон, без обычной рамки,
с кружком hit-testing, кнопками, логами и моделью `ollama-cloud`.

- Каталог: `JarvisSiriOrb/`
- Сборка: `cd JarvisSiriOrb && make`
- Запуск: `open JarvisSiriOrb/build/JARVIS.app` (или `./JarvisSiriOrb/build/jarvis` из терминала)
- Логи: `JarvisSiriOrb/jarvis.log`
- Используется только `ollama-cloud/beam`, vision: `ollama-cloud/glm-5.3-flash`
- Полная история логов не публикуется: создается пустой локальный `jarvis.log`, а `*.log` в `.gitignore`

Старая версия в корне репозитория сохранена и не изменена.

## Решение проблем

- **«Не найден локальный сервис OpenCode»** — запустите `opencode` и проверьте,
  что создан `~/.local/state/opencode/service.json`.
- **Ошибка авторизации или ответа модели** — проверьте настройки и авторизацию
  провайдера в OpenCode, доступность выбранной модели и состояние сервиса.
- **Не собирается проект** — установите Xcode Command Line Tools и проверьте,
  что доступны `clang++`, `make` и системный `libcurl`.
- **Не работает голосовой ввод или скриншот** — проверьте разрешения JARVIS в
  **System Settings → Privacy & Security**.
- **Не слышно ответ** — проверьте громкость и доступность системной команды
  `/usr/bin/say`.
